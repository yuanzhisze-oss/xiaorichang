小日常｜每日行程提醒 App（PWA 版本）

目前可提供的實際格式：可安裝的網頁 App（PWA）原始檔案包。
本製作環境沒有 Android SDK / Gradle，因此此處不能直接編譯出 APK。

功能：
- 首頁顯示目前時段或下一件事
- 週一至週日固定行程與週檢視
- 完成、延後 10 分鐘、跳過
- 新增自訂行程、重設完成狀態
- 通知權限與提醒提前時間設定
- 行程與狀態保存在本機瀏覽器
- 基本離線快取（首次開啟後）

安裝方式（Android）：
1. 將此資料夾部署到支援 HTTPS 的靜態網站空間（例如 GitHub Pages、Netlify 或自己的 HTTPS 網站）。單純從 ZIP 直接開啟 index.html，通常無法啟用 PWA 安裝、Service Worker 和通知功能。
2. 用 Android Chrome 開啟網站。
3. 點 Chrome 右上角「⋮」→「安裝應用程式」或「加到主畫面」。實際字樣依 Chrome 版本而異。
4. 開啟桌面上的「小日常」，進入「設定」允許通知，再按「測試通知」。

提醒限制：
- 本版本的行程提醒在 App 頁面保持開啟時運作；頁面每 20 秒檢查一次行程。
- 即使允許通知，網頁 App 在完全關閉、系統凍結背景、手機省電限制或裝置重新啟動後，也不保證能準時通知。
- 若要求關閉 App 後仍可靠定時提醒，需原生 Android APK 使用 AlarmManager/WorkManager 等機制並妥善處理 Android 版本及電池最佳化限制；本包不是 APK。
- 資料存在本機瀏覽器儲存空間，清除網站資料或更換裝置可能會遺失。
- Google 日曆中的假日與作業截止日不會自動匯入本 App；這是刻意維持兩者分工，避免首頁塞滿事件。
